# 物品特效：把用户反馈变成可验收的修改

先读 items.md 确定渲染管线。下列是按需选取的效果规则，不要求每个物品都添加火焰、太极、八卦或星点。用户明确指出“全部重做”时，重建有问题的风格与空间关系；仍保留其认可的主体和资产约定。

| 用户反馈 | 应执行的修改 | 验收证据 |
| --- | --- | --- |
| “低清像素，像火焰；两边有，中间没有” | 重绘块状火舌、亮芯与阶梯边；按需要组织外缘、底部和中央火床/火舌的覆盖。中心效果应有正侧视可见体积感，不能仅补一张俯视圆盘 | 正面、斜侧、俯视以及整段循环看中部与边缘；排除遮挡、反面剔除、透明空帧导致的假缺口 |
| “太极不会转，也不是像素风，还有黄圈” | 在逻辑像素网格重绘；追踪实际帧序与旋转方向。静态物品可用旋转图案序列，有厚度转动需运行时方案。定位无意义光圈的图层/面并移除 | 数个明显不同的角度和连续循环；轮廓不抖，阴阳鱼不过度糊成团；检查有无遗留黄圈。不能只改组名 |
| “像没抠干净” | 在黑白背景逐帧查 alpha 外缘、残留底色、孤立杂点、漂浮色边和多余面；按像素轮廓重建 | 透明边缘干净，物品轮廓可读；不得靠大光晕盖住残边 |
| “云雾做方块云，用透明颜色材质” | 以少量错落 cuboid 构成疏密与体积，使用克制的像素材质和有限级 alpha；保留云块间空隙 | 多视角仍像有体积的云；目标渲染层确实支持需要的半透明；动态时无闪烁、叠黑、忽隐忽现的非设计跳变 |
| “闪电应该竖着” | 主轴按场景竖直方向，从来源指向落点；允许阶梯折线、少量支叉和短促分段闪现 | 检查最终变换后的空间方向与主干跨度，不能仅把横纹 PNG 换名字；发射源和终点合理 |
| “卦象投影变成现在两倍大，更亮” | 针对该次修改，以修改前的投影可见图案宽/高为基准，各放大 2 倍；调整卡片、留白、逻辑像素数与相对位置。保留符号结构；用高亮核心和受控外缘增强亮感 | 同相机比较可见宽高为 2 倍（面积约 4 倍），无裁切/重叠遮蔽。实际发光能力另列验证；不把“2 倍”变成日后所有投影的默认值 |
| “星星像原版 wax_off 粒子” | 有目标版本资源时查看实际 wax_off 的粒子定义、所引用 sprite 及帧序；提取少色、硬边、短促闪烁的尺度语言。没有原版资源时明确为风格近似 | 小尺寸可读、无写实镜头星芒；若用卡片模拟，说明不具备真正粒子运动/朝向，不能宣称已调用原版粒子 |
| “上下、里外像素大小不一样” | 按 pixel-style.md 比较所有层的世界空间像素与色块大小；同时修 UV、几何和图案频率 | 同材质主体内外、上下不突变；特效也不出现粗细无理由混杂。贴图变成低分辨率不是充分证据 |

## 特效必须有空间和材质分工

主体负责可辨认的体量，火焰负责燃烧方向，云负责体积，符文负责识别，星点只作点缀。每一层应有来源、朝向、厚度/覆盖、遮挡和时间节奏；没有作用的圈、光片和噪点不默认添加。把效果逐层开关检查，不能让装饰吞掉主体轮廓。

火焰可用少量交错卡片，但应从前后左右检查中心覆盖；不要靠密铺大量共面贴图制造浓度。像素太极/法阵的平面朝向要与其用途一致，检查 UV 翻转造成的旋向变化。有限角度的循环序列需看真实连续播放，不能只用首尾相同证明转动顺畅。

方块云的“方”来自几何体积与轮廓，不是给一张软烟雾图加马赛克滤镜。静态格式若必须用逐姿态显隐来模拟漂移，先算总元素数、总面数、透明面覆盖、纹理数量和循环周期；说明它是兼容性折中，避免直接照搬案例的规模。

## 结束条件

相关反馈逐项通过实际画面/动画验证后停止装饰性加料。无法实测的项明确标为待验证，不用静态审计“0 errors”替代风格、发光或播放验收。

## 沿用既有火焰时，分别调整高度与速度

用户要求“持续高燃”时，先分清是否要保持火焰轮廓的升腾、抬高最低高度、降低沸腾频率；不要直接冻结最高帧或换成完全不同的火形。七煞鼎/混元神鼎对话最终要求：保留原火形，最低高度抬到原范围中点、最高点不变、沸腾速度减半。这是该次参数，不是所有火焰默认。

先记录原循环的最低/最高可见火舌、周期及其与卦象/符文的遮挡关系。相同相机比较完整循环，确认中心仍有火、火舌持续升腾、主体符号未被新火层遮住；只改周期不能证明高度正确，只抬高最低点也不能抹掉运动感。
