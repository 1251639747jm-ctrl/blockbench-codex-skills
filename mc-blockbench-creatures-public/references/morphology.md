# 按形态选择结构与运动，不套龙模板

## 建模前的最小设计说明

记录尺度、主要轮廓、承重或悬浮方式、推进来源、感知器官、可动关节、性格和动作清单。使用用户参考图和已有满意部分。没有证据时不要给所有角色添加尾、角、牙、翅、鳞片、毛发或发光装饰。

分开看三个维度：形态（长什么样）、运动环境（地面/空中/水中等）、表现性格（笨重/机敏/冷静/诡异等）。它们不是固定绑定：大体型可以灵活，小体型也可以笨重；鸟不一定飞，机械可以四足，也可以悬浮。

人形表演优先读 [humanoids.md](humanoids.md)；二足鸟兽仍按自身形态选择本表。下表可帮助混合角色拆分人体与非人形运动系统。

## 形态参考矩阵

| 类型 | 建模与骨骼重点 | 动作活性与支撑重点 | 避免误套 |
|---|---|---|---|
| 二足/人形/类人怪物 | 骨盆、胸腔、肩、髋、膝踝，按需手指/面部 | 支撑腿与重心转移，肩胯反向协调，视线/躯干先导 | 四足对角步态、龙趾或固定长尾 |
| 四足兽/爬行动物 | 胸腹、肩胛、骨盆、前后肢，按物种区分跖行/趾行/蹄行 | walk/trot/gallop 等按设定选，足底支撑与肩胯传力 | 所有四足都同一抬脚顺序、只转脚跟 |
| 六足/多足节肢 | 体节、足对、口器/触角、外骨骼接缝 | 三足支撑或相位波按结构，维持多点支撑，触角可感知 | 强加脊椎动物肩胯和呼吸 |
| 鸟/蝙蝠/翼行 | 胸背、翼根到翼尖；羽翼、翼膜或翼指分别设计 | 上下拍不对称，恢复拍与推进拍区别，降落/收翼有支撑 | 全部翅膀是同一硬板、羽翼套龙翼指 |
| 鱼/水生/鳍行 | 主推进尾、躯干或鳍，身体流线由像素体块表达 | 鱼类横摆、海兽上下摆或其他明确模式；鳍配合制动转向 | 把地面脚步转成游泳、所有尾鳍同轴摆 |
| 蛇/蠕虫/无肢长身 | 必要分节、连贯截面与弯曲余量 | 沿身传播弯曲波，接地/蠕动方式与推进同步 | 只转 root 就当整条身体弯曲，默认补四肢 |
| 触手/软体/流体 | 能表达卷曲、收缩、轮廓变化的有限控制链 | 局部收放、接触黏附、体积与形变节奏 | 强加脚掌，或用逐像素立方体模拟光滑流体 |
| 植物/菌类/树人 | 茎干、分枝、叶片卡片，运动支点有归属 | 生长/卷叶/弯曲、风与主动运动分清，按设定根系支撑 | 强制眼嘴、动物呼吸或普通跑步 |
| 机械/构装/傀儡 | 关节轴、壳体、驱动来源、限位和互相避让 | 齿轮/连杆/液压或设定驱动有因果，启动/急停有惯性 | 默认软体弹性、肉体呼吸或无限扭转 |
| 悬浮/元素/无明确骨架 | 清晰主轮廓、核心/附属结构层次 | 有节律的悬浮、展开、聚散与响应，不靠每 tick 随机噪声 | 强加四足或无意义的落地踩踏 |
| 混合/幻想生物 | 明确一个主运动系统，再连接其他器官 | 不同运动模式分别设计支撑和过渡 | 把所有参考特征堆在同一模型上 |

矩阵是选型参考，不是解剖学穷举或制作清单。只为当前角色实现需要的结构。现有低面数风格不应因应用本技能变成复杂生物模拟。

## 跨形态通用的活性

运动应有动机、领动、传递、接触/推进和收势，但表现载体随形态改变。动物可以观察和呼吸，机械可以传感器转动与动力待机，植物可以卷叶和轻微弹性，元素体可以聚散。休眠、伏击、冻结或死亡中的静止可能正是正确表现。

## 泛化自检

在交付前问：若把角色名换成鸟、甲虫或傀儡，当前哪条规则会强迫它长出不需要的骨骼或套用错误步态？将这种规则限定到相应形态或案例，不能写成通用 MUST。

不复制墓龙的骨骼编号、攻击时长、尺度、配色、伤害规则或整套动作名；可复用的是骨骼传动、支撑、可读性、渐进验证及资产交接方法。
