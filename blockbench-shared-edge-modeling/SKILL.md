# Cube 共边建模

交付可编辑 Cube 模型。所有造型与尺寸来自本次参考和用户指定基线；**曲线接头以两个 Cube 旋转后的同一条实际边为准**。本技能只包含制作方法和执行标准。

## 必须落实的执行约定

1. **确定基线。** 读取活动项目与磁盘文件，保存起始副本，记录认可部位、本轮范围、格式、总预算和分部预算。以后来的明确要求更新约定；用户要求保存或停止时保存当前版本。
2. **查看本次参考。** 实际打开整体图、相关局部和参考 Mesh 隔离视图，记录源部件、顶点/轮廓对应、世界尺度、前向和相机。隐藏部分按已知结构补全并标明推断。
3. **完成样件再扩展。** 每类曲线先完成一组实际接头。核对一侧的完整形状、连接和朝向后，再制作有参考依据的镜像件。
4. **逐接头兑现共边。** 保存两块 UUID、实际边端点、宽厚、法向、父变换与用途。读取旋转后的八角点，核对共同边的两个端点；数值和原生画面均检查后，才记录本阶段通过。
5. **由几何承担轮廓。** 主体大块填体积，同面斜边确定轮廓。外表面保持在目标表面上，厚度向内建立；转折内侧需要实体时按实际内角补齐。
6. **用实际画面验收。** 检查正常观看距离及接头近景，覆盖正面、严格左右侧、背面和相关斜视。确认外边、体积、窗口、端面与纹理连续；每项结论附文件和视图。
7. **保持认可资产。** 按本轮允许部位调整，保留其他几何、纹理、姿态和层级。只要求减块时，按保形优化流程核对等价性。

这些条款是本技能的验收条件。未检查项记为“未验证”，未满足项继续在授权范围内修正。内部阶段自行推进，无须逐阶段请求用户确认。

## 参考到几何

建模前读 [共边构造](references/shared-edge-construction.md)。

- 将轮廓分为根部、长直段、曲率变化、回折和末端，仅在结构需要的位置分段。
- 分别记录轴线路径、各高度截面、每列外表面方向与整体姿态。前后、内外面的转折高度按各自参考保留。
- 用同一份共享顶点/截面表构造相邻片。同面区域用大块，转折保留明确共边。
- 使用参考 Mesh 时记录源部件、顶点/面 ID、原始坐标及坐标变换，维持与参考图的视角对应和整体比例。
- 宽度、厚度分别受参考约束；袖腿同时保持外缘、内缘、前后深度及截面收放。

## 发体、袖腿与连续附件

- **发体：** 保持头顶、发根、刘海上部、鬓发根部和后发的连续层次。每束独立确定宽厚、外展、前后变化及末端；下缘和缺口按参考保留。
- **袖体：** 对应肩、上臂、肘、前臂鼓起、收口的真实截面。各列外边连续，末端接入统一袖口基准；白条和罗纹依附完成的承载表面。
- **腿部：** 恢复大腿、膝前、膝后、小腿及踝端的独立边界。以裙下露出长度检查比例，以裙内髋部到膝、膝到踝的完整长度安排绑定空间。
- **布带与饰边：** 固定根部、路径、厚度和末端，按实际壳面逐段确定方向与离面距离；基础面改变后同步连接与 UV。
- **内部面：** 经几何与多视角确认完全内部的面，可按目标导出表示隐藏。开口内壁、裙底可见面和动作中需显示的面保持完整。静态外壳、封闭体积和运动分别验收。

## 手与鞋

- 隔离参考 Mesh 的手，辨认掌体、掌侧、拇指、弯指体和缺口的实际连接，再按参考与用户风格要求分块。
- 记录掌向、腕截面、指根、弯折端点与内收方向。掌指按实际外边接续，掌侧与拇指接面连续。
- 左右手保持正确手性，分别核对掌心、拇指位置和袖口衔接；手部预算包含本次约定的全部掌指体。
- 鞋按踝、后跟、脚背、鞋头、鞋底和横带制作。鞋底接地，鞋面和承托体连续，横带贴合真实鞋面。
- 需要动作时，先确认父组、枢轴、完整肢体长度与关节体积，再单独验证动作。

## 配色、UV 与保形减块

执行前读 [贴图与保形优化](references/texture-and-optimization.md)。

从参考提取主色、亮色和暗色，手绘沿发束、衣片组织的像素块。相邻面使用一致的像素基准。图集组装时保证独立纹理 UUID 唯一、索引与逐面 UV 对应，保存后重新打开核对实际颜色。

减块检查完整包埋的重复体、同组共面同色矩形、可合为实体的对应正反面。逐项记录前后对象、表面/体积范围、材质和运动归属，在相同相机与光照下比较实际模型。

## 交付门槛

| 检查项 | 必须保留的证据 |
|---|---|
| 基线与范围 | 起始文件、允许修改部位、当前预算和统计口径 |
| 参考对应 | 实际看过的参考与隔离 Mesh、坐标或顶点依据 |
| 共边 | 两块 UUID、实际端点、文件指纹、端点误差和原生近景 |
| 表面与体积 | 邻接表面、厚度方向、内角、开口的检查视图 |
| 材质 | UUID/索引、嵌入资源、保存后原生重开的显示 |
| 减块 | 同条件前后投影、几何等价检查和实际像素差异 |
| 数量 | 全部 Cube（含隐藏块）、分部统计，分组与辅助对象另列 |
| 交接 | 明确的 BBModel 最终入口、备份、未验证事项 |

使用 [audit_shared_edges.py](scripts/audit_shared_edges.py) 对保存文件及声明的接头作只读核查，输入见 [共边构造](references/shared-edge-construction.md)。它检查实际角点和静态父组旋转；视觉、封闭体积、动画和未登记的接头仍由执行者验证。

技能中的示例数值不替代本次参考；数值通过只支持所检查的数值结论。按用户当前范围完成制作、检查与保存。
