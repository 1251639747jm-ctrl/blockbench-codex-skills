# 手绘贴图与保形减块

## 手绘像素贴图

1. 从原参考的代表性材质区域提取主色、亮色、暗色并记录色板。
2. 沿发束、衣片、罗纹、条纹方向组织像素块，相邻 Cube 共用一致的世界或表面像素基准。
3. 脸、眼睛、耳朵和衣物分别保持材料对应与合适 UV，认可的五官纹理局部保留。
4. 为独立纹理设置唯一 UUID，同步数组索引、`id`、有效面引用和 UV 尺寸。
5. 按用户选择内嵌或外链资源，保存后原生重开，核对实际像素、资源身份、颜色和纹样连续性。

## 保形减块

| 方法 | 必须成立的条件 |
|---|---|
| 共面矩形合并 | 运动归属、表面和材质一致；替换后的可见多边形并集与原来一致 |
| 正反面合为实体 | 法向相反、平面平行、矩形投影重合；一个 Cube 的两个面分别保持对应 UV 与颜色 |
| 包埋体移除 | 所需静态及运动状态下整个待移除体被保留几何覆盖，接口与必要内部体积完整 |
| 内部面整理 | 被保留体积完全包住，且目标导出、相关视角和姿态无需显示该面 |

同色面可复用对应颜色纹理；带花纹的面同时验证 UV 与像素。具有动画用途的对象按共同骨骼、枢轴与运动归属合并，保留髋、肩、膝、肘、腕踝的必要接入长度和体积。

## 等价验收

1. 保存优化前基线及独立候选。
2. 使用完整父变换比较实际表面/体积；共面合并可检查多边形并集对称差，包埋检查覆盖整个体积。
3. 固定相机、尺寸、背景、照明和姿态，原生渲染正、侧、背、顶及必要斜视。
4. 比较实体轮廓与 RGB/Alpha，记录变化像素的位置、数量与幅度，并打开相关近景判断。仅在实际比较完全一致时使用“像素完全一致”。
5. 根据证据保留删减，明确未验证角度或动作。
6. 读回最终文件，核对 Cube、分组、UUID、纹理与资源完整性。

## 预算与交接

使用用户当前总预算与分部预算，统计包含隐藏 Cube；手、袖口、鞋底按事先写明的口径计入，组/骨骼和参考辅助对象另列。预算更新记录适用范围。

交付清晰的最终 BBModel 入口，保留优化前备份和检查报告。用户要求保存当前进度时即保存，准确记录数量与未验证事项。
