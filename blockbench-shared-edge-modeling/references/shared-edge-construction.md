# 实际共边与连续体构造

## 一条边驱动两块

每个转折定义世界边 `E=[P0,P1]`。它是两个 Cube 各自八角点之间的一条完整边，两个端点均对应。

对相邻两片分别确定朝外法向 `Ni`、从共边进入本片的方向 `Di`、长度 `Li` 与厚度 `ti`：

```text
X = normalize(P1-P0)
w = |P1-P0|
V = Ni × X
R = [X V Ni]
Di = +V 或 -V
C = (P0+P1)/2 + Di*Li/2 - Ni*ti/2
S = [w, Li, ti]
from = C-S/2
to = C+S/2
origin = C
```

`Ni` 与 `X` 垂直，`R` 为正交右手坐标架。外表面位于 `C+Ni*ti/2`，朝向共边的那一端落在 `[P0,P1]`。两片使用自己的法向与长度，保持参考折角。

按目标工具实测约定转换 Euler。Blockbench 5.2.2 的相关 Cube 流程使用 `Rz·Ry·Rx`；SciPy 对应 `Rotation.from_matrix(R).as_euler('ZYX')[::-1]`。其他版本、格式或父变换条件先核对原生角点。

变截面片先确定共同截面上的边，再配置其余边界。宽面可由主块与同面斜边组成。长边对应多段短边时逐段登记；要求“两块完整共边”的接头使用端点和长度一致的完整边。

## 外表面、厚度与内角

1. 计算完整八角点，确认外表面与目标表面一致。
2. 在共边处计算各片内侧边：`P0-Ni*ti`、`P1-Ni*ti`。
3. 需要补齐的内角从这些实际点确定，内角实体处于目标内部并连接相邻体积。
4. 核对全部厚度角点和端面相对于邻接表面的内外关系，再扩展曲线。
5. 保留参考中的孔与内壁；需要封闭的体积另验闭合。

各列面可有不同转折高度、段长和结束位置。进入同一袖口时，以统一端平面及实际截面核对所有末端角点。

## 主体大块与同面斜边

- 在局部平面中建立参考轮廓，顶点对应本次图或 Mesh。
- 大矩形填充内部，斜边条的外沿位于目标线段，宽度向内。
- 共面片保持相同平面、材质空间和厚度区间；转折两侧使用自己的法向及同一份共边端点。
- 规则矩形区域整体建块，渐窄区域保留连续边并合并内部矩形。
- 四点的共面性先作检查；需要多片时按共享顶点拆成平面片，并在实际边相接。
- 对完整部件作外展、调直或摆姿时，同时更新连接、附着条纹与 UV。

## 保存文件的只读检查

脚本支持静态、无额外缩放的 BBModel Cube，读取 `from/to/origin/rotation` 和父组旋转。其他变换按原生评估后的角点另验。

角点索引 `0..7` 的位 0 选择 X 下/上界、位 1 选择 Y、位 2 选择 Z；恰好一位不同的两个角点构成真实边。

接头声明示例（替换为实际 UUID、边索引与目标坐标）：

```json
{
  "rotation_order": "ZYX",
  "tolerance": 0.00001,
  "seams": [{
    "id": "本次接头ID",
    "a": "第一块UUID",
    "b": "第二块UUID",
    "edge_a": [4, 5],
    "edge_b": [6, 7],
    "expected_edge": [[0, 0, 0], [1, 0, 0]]
  }]
}
```

`edge_a/edge_b` 可同时省略，让脚本查找两块的 12 条真实边。可选 `expected_edge` 将检查约束到目标边。登记每个需要验收的曲线接头；空表不算数值通过。

```text
python scripts/audit_shared_edges.py 模型.bbmodel 接头声明.json --report 共边检查.json
```

报告保留模型 SHA256、实际边、端点误差与数值结论。允许端点顺序相反，使用欧氏距离。视觉朝外性、未登记接头、纹理、封闭体积与动画由执行者另验。
