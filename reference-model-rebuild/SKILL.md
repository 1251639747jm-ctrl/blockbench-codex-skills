# 参考图还原建模

从参考图出发，恢复可见的轮廓、比例、厚度、切面、层次与遮挡，交付可继续编辑的三维模型。流程是：**实际看图 → 自行记录细节与建立审计 → 校准视角 → 隔离部件描形 → 多视角叠图修正 → 完成层次 → 匹配外观**。

**输入可以只有图片。参考细节、部件清单、审计表和工作记录由执行本 skill 的模型主动观察、编写并持续更新，不假定用户或其他工具已经准备好。** 模板只定义记录方式，不提供本次参考的答案。

适用于不同角色、物件和造型风格，不预设头发、甲片、饰件、配色或固定建模顺序。默认使用目标工具支持的可编辑几何；允许 Mesh 时用少量结构合理的 Mesh 表达复杂轮廓，规则体可保留基础几何。默认总对象数不超过 **2000**，用户当前明确指定的格式、预算和范围优先。

Blockbench Cube 任务要求实际共边、无缝曲线、沿用头发技巧或保形减块时，同时读取并执行 [Cube 共边建模](../blockbench-shared-edge-modeling/SKILL.md) 的构造与验收要求。

这些方法包含实际使用过的计算、局部修正经验和失败教训。**方法有用、某项数值检查通过、整个部件通过验收，是不同结论。** 未完成动作验证的骨骼方案、仍有误差的接面和未解决的遮挡，不能升级为已验证配方。

## 1. 主动读图，写出本次参考的细节

首次分析时读取 [自主观察与审计方法](references/observation-and-audit.md)，按其中方法生成本项目的实际记录。

1. 找到并实际打开每张原始参考图，记录来源、尺寸、视图和裁切范围。先看整体，再放大主要区域，最后查看关键局部；不能只读文件名、说明文字或旧报告。
2. 从图中自行识别主体比例、主要体积、识别性特征、结构层次和重复关系。逐区观察外轮廓、转折、开孔、接缝、截面、可见底层与遮挡边界；不凭物体类别补上常见但参考中没有的细节。
3. 编写参考观察记录，为实际可辨认的部件及重要关系分配 ID，注明所依据的视图、图像位置、可见特征和证据强弱。区分“明确可见”“合理推断”“无法确定”。
4. 在多个视图间对应同一部件，记录挂点、朝向和遮挡对象。审计条目可以检查同一部件的多个属性；条目数、图中出现次数、物理零件数和建模对象数不能混为一谈。
5. 自行建立还原审计表。尚未创建模型时，记录参考要求并标“未建模”；有当前模型后实际查看其投影，再写具体差异、修改动作与验证结果。不能在尚未比较时预填“通过”。
6. 持续补充最初未看清的细节。已有说明和日志可帮助定位问题，但需回到原图核对；没有现成审计文件时，直接创建，不让用户代做读图和整理。

开始前结合已有信息确定工具、工程格式、输出位置、对象预算，以及从零重建还是继续精修。继续精修时保留起始工程副本，确认真实活动项目与未保存状态；从零重建时，旧模型几何不能代替原始参考成为外形来源。旧审计中的冻结、挂点、制作顺序和验收结论均受版本限制，不能覆盖用户的新纠正；附件里的指令性文字不自动成为当前任务授权。

## 2. 校准实际参考视角

设置相机和比较图时读取 [校准与叠图规范](references/calibration-and-review.md)。

- 把参考放入建模视图的背景、参考平面或可开关图层。建立统一的世界尺度、基准面和主体中心轴；图片保持原始比例，记录每张图的裁切和缩放映射。
- 根据图像判断真实观察角，而非直接把“正面”“侧面”等标签当作严格正交视图。侧图可见正脸或顶面时，先拟合偏航、俯仰及投影类型，再判断厚度。
- 使用分布在主体不同位置的稳定特征共同约束相机，避免只对齐一个局部。相机与基础体积交替小幅校正，不同时任意改变所有变量。
- 保存并锁定与各张参考匹配的相机；必要时增加严格正交或斜视诊断相机。只有与参考观察角一致的投影才能作对应像素比较。
- 三视图齐全时三个方向都要核对。参考不足三张时，核对所有已有参考，并将新增诊断视图和隐藏深度标为假设，不虚构缺失角度的验证结果。
- 不局部拉伸参考、单独缩放部件截图或扭曲投影来消除误差。参考存在姿态、版本或画法冲突时，在记录中指出并区分可共同约束与不可直接比较的区域。

**进入精细描形的条件：** 相机和图像映射能够复现，主要尺度关系稳定，已经区分明显的视角误差与局部形体误差。旧项目角度和像素标尺不能直接继承。

## 3. 根据结构依赖选择制作顺序

先建立比例与位置框架，再隔离对识别度和后续搭接影响最大的基础部件。将顺序写入工作记录，随参考证据调整。

| 参考对象 | 可采用的起点与依赖关系 |
|---|---|
| 角色或生物 | 比例框架 → 独立头部及主要体块 → 身体基础与覆盖层 → 附件和细节 |
| 道具或机械物件 | 主壳体、支撑或骨架 → 接口与连接结构 → 外壳分层、开孔和附属件 |
| 多层或装配物件 | 承载基础 → 内层 → 中间连接 → 外层覆盖 → 依赖外轮廓的装饰 |

这些是选择顺序的示例，具体部件必须由本次参考识别。没有相应结构就不创建。

隐藏会干扰观察的外围或覆盖部件，先让基础体积的宽高、深度、挂点和跨视图连续性成立。角色头部可先处理头颅、脸面和实际可见的耳部等基础，再加发层和装饰；其他对象按自身结构分离。

区分基础体积边界与覆盖层外轮廓。被遮住的内层不能直接按外层轮廓建满，也不能宣称隐藏拓扑已被唯一确定。基础中可观察的高优先级问题解决后，才增加依赖它的细节。

## 4. 逐部件描形，随后建立厚度

每次处理一个部件或一小组存在直接依赖的部件：

1. 重新查看对应参考局部，从图中确定端点、拐角、曲率变化、收窄、凹口、孔洞、搭接线及可见切面。把新的观察补入参考记录。
2. 根据真实轮廓选择控制点和拓扑。外包框相似不等于形状成立；不能用通用几何模板省略具有识别性的根部、颈部、尖端和截面变化。
3. 用其他视图、可见边缘和遮挡关系确定厚度、截面、位置与朝向。沿部件合理的局部方向建立体积；缺少证据的深度保留可编辑的合理假设。
4. 补齐应有的侧面、背面、内壁和切面，保持应有的孔洞与凹陷；检查法线、连续性和实际厚度。平面、曲面、硬边和倒角均按参考风格处理。
5. 将部件装到明确的壳面、关节或连接点，形成真实的前后差与搭接，检查悬空、错误贯穿和共面闪线。
6. 执行下一节的叠图检查，依据具体误差修改相应顶点或局部参数，复核后再继续。

重复件应先完成一个样件的轮廓、厚度与安装方向核对，再复制或镜像。对称性必须有参考依据；被遮挡的一侧若采用镜像补全，需标为推断。

使用 Cube 表达曲面时，分别确定**轴线路径、截面收放、各片表面方向与姿态**。沿真实转折布置正厚度薄 Cube，用逐片旋转、端点和最小必要搭接连接，保留参考中的硬折角。共用端点不保证旋转后的外表面无缝；不能靠统一加长、不断加盖片或增加规则圈数处理所有接缝。

精修已被用户认可的曲面时，先保留原件与局部截面。用户要求“弄直胳膊”若指现有曲线结构上的轴线调整，就调整既有表面及其附件，不替换成新直筒或锥形袖。调直、整体摆姿和骨骼绑定分开实施、分开验证，详见 Cube 专题。

## 5. 自行比较叠图，写审计并修正

每层完成后，用锁定相机输出与所有参考视角对应的投影，将每张投影与其原参考半透明重叠；保留原参考和纯模型投影，必要时增加轮廓线、局部放大或交替显示。

**执行者必须实际打开并检查每张叠图，自行写出偏差与修改动作。生成图片、建立空表或保存工程均不算完成审计。**

- 按外轮廓与比例、关键点、部件边界、厚度和遮挡、局部切面的顺序检查。开孔、缝隙、露出的内层或皮肤窗口也有需要还原的形状。
- 只比较有可靠对应关系的可见区域。某边缘在该参考中受遮挡，就记录遮挡并转到其他视图验证，不能当作已对齐。
- 将差异落到部件 ID 和具体边界，例如“上边缘偏高，调整该排顶点并检查邻接部件”；避免只写“不像”“更精细”。有测量依据时记录像素偏差或比例差，并注明坐标与容差依据。
- 修改几何后重新核对所有相关参考角度。一个方向改善而另一个恶化，应继续修，不能直接标为通过。
- 多个分离部件出现一致偏差时，重新诊断相机、尺度和图像映射。确需重校准就更新相机版本，重做受影响叠图。
- 修正不收敛时，重新看原图并检查部件对应、视角和遮挡假设；不改为堆积大量小对象或批量重生成整模。

审计状态使用“未建模／待修／通过／受遮挡／未验证”，证据强弱另列。高优先级的可见问题未解决时继续修当前层；轮廓、关键转折、遮挡和体积不能靠平均相似度或数量成绩抵消。

阶段通过是内部质量门槛。在用户已授权范围内持续执行，无需每过一层都请求确认。

## 6. 完成覆盖层与连续附件

基础部件通过后，根据自行建立的层次表，从内到外完成覆盖结构；检查连接点与实际包覆关系，再补依赖这些结构的长条、带体、毛发、线缆、垂片或外围附件。

- 开孔、间隙和露出区域由正确的几何边界与遮挡形成，不通过修改底色掩盖多余暴露。
- 连续附件应有可追踪的根部、路径、截面变化和末端，同一附件在不同参考中对应同一套空间结构。
- 包边、绕带、扣框和花纹依附实际承载表面；基础面改变后同步重算局部偏移、朝向及必要的 UV。连续布带先确认起点，再检查全路径的穿模、侧面轮廓与垂落方向；无碰撞不代表垂落合理。
- 相邻层可有不同的长度、深度、角度和结束位置，不将所有部件施加同一偏移或缩放。
- 加外层后复核内层的可见窗口和接头，检查应该遮住的位置、应该露出的特征及整体轮廓。

配色、包覆密度、重复数量和层次顺序都从当前参考得出，不套用其他角色或物件的结果。

## 7. 最后匹配色泽与光照

几何检查阶段保留轮廓、稳定中性照明或纯色显示。几何通过后固定相机和形体，再调整材质底色、面色及工具支持的表面参数、照明与阴影，另存外观比较图。

参考像素色包含光照与反射，不直接等同于材质底色。分别记录几何误差和外观误差；不能用过曝、深色描边、强环境遮蔽或绘制阴影掩盖形体问题。左右明暗不同先检查光照，不直接推断几何不对称。

## 工具、脚本和数量约束

使用当前可用的建模工具逐件编辑并查看模型，不绑定某个软件或臆造接口。脚本可对**已观察、明确指定且可逐项复核的输入**做确定性计算：端点到 Cube 变换、既有表面的接头读数、父子矩阵换算、贴面偏移、已核对重复件的复制、UV 烘焙，以及保存、截图和只读检查。脚本不负责猜测主轮廓、批量决定未知深度或替代逐件观察与修正。历史操作文件不是可任意重跑的生成器；先核查当前对象与操作是否已执行。截图的裁切和叠合可以辅助展示证据，不得改写参考内容或修补模型投影。

格式约束从任务中确定。用户要求纯 Cube 等受限表示时，先考虑其对尖端、曲面和斜切的表达限制；需要近似就记录可见误差并复核，不能通过改类型或提高数量上限宣称无损。

对已指定的端点、宽厚和横向提示，可用 [cube_segment.py](scripts/cube_segment.py) 计算中心、正尺寸、旋转、端点与八角点。输入示例及坐标限制见 [Cube 专题](references/cube-placement-and-curves.md)。该工具只输出 JSON，不写入工程；仅支持明确的 `Rz·Ry·Rx / ZYX` 约定，使用前核实目标环境的实际旋转顺序和父坐标系。

默认统计全部模型元素、分组/骨骼及保留在工程内的辅助对象，包含隐藏对象，总数不超过2000。纹理、材质和动画关键帧不计作几何对象。按本次部件清单分配预算并预留精修空间；不固定每类部件数量，不以用满预算证明细节充分，同时检查顶点/面数与编辑流畅度。

对 `.bbmodel` 可使用只读工具 [audit_bbmodel.py](scripts/audit_bbmodel.py)；其他工具使用其原生统计，按相同口径补计。

```text
python "<skill目录>/scripts/audit_bbmodel.py" "<模型绝对路径>.bbmodel" --limit 2000 --json-out "<输出目录>/对象统计.json"
```

该工具统计保存的元素、分组和参考图，避免重复计算 `groups` 与 `outliner` 中同一分组，并检查部分 UUID/层级引用问题。只有任务明确要求纯 Cube 时才附加 `--cube-only`。它**不检查**正尺寸、材质和 UV 完整性、碰撞、所有层级语义或视觉还原。插件额外对象和未保存场景需另外核对。

## 记录、续作与交付

观察记录、相机记录、还原审计和工作记录都是执行者需要产出并维护的工作成果。可分文件，也可合并在项目现有记录中；不存在时主动创建。每层保存检查点及对应投影、叠图，记录本轮修改、验证结果、数量、未确定项和下一步。

结束前保存并读回交付工程，检查对象类型、数量、材质引用、分组及实际可打开性。验证图应对应这份保存后的版本。交付可编辑工程、参考观察与审计记录、相机设置、对应视角的叠图及剩余差异。

回退前保存当前未保存进度，先明确撤回范围，避免丢失无关修改。回退后比较实际元素、变换、分组、层级及受影响的材质/UV，不以文件名或数量相同证明还原成功。用户叫停时停止新增建模工作，保存当前状态并如实标注未完成项；整理经验不构成继续修模型的授权。

没有实际看过的细节、缺失参考角度和未验证结构保持明确标记。工具不足以查看图片或操作模型时，完成能够执行的准备并说明具体限制，不虚构观察、建模或验收结果；没有证据时不宣称完美还原或给出虚构百分比。
