# Cube 摆放、旋转与曲线接面

用于纯 Cube 或以 Cube 为主的可编辑模型。下文的 Cube 指可设置宽、高、厚和旋转的长方体，不限于等边立方体。纯 Cube 是按任务选择的表示约束，不推广成所有参考建模的默认要求。

内容索引：明确输入；曲线与表面分段；局部坐标架；计算工具；接缝诊断；端面与袖口；斜边薄片；保形调直；骨骼边界。

## 1. 每片 Cube 的明确输入

每片至少记录：目标 ID、中心 `C`、正尺寸 `S=[w,l,d]`、旋转 `R`、旋转原点 `O`、父组、材质/UV，以及它依据的参考边界或承载表面。名称用于识别，实际编辑优先使用已核实的 UUID。

新片采用中心旋转轴且输入坐标处于同一父坐标系时：

```text
from   = C - S/2
to     = C + S/2
origin = C
```

三维尺寸必须为正；薄片也需要厚度。`from/to` 是旋转前的参数，不能当作旋转后的世界包围盒。旧件不一定以中心为轴，其旋转后中心为：

```text
C0 = (from + to)/2
C_in_parent = O + R · (C0 - O)
C_world = M_parent · [C_in_parent, 1]
```

读取真实显示几何或完整父矩阵后再移动、重挂父组或量接头。只改一个旧件的 `origin` 会改变旋转结果，不能据此宣称几何位置保持。

## 2. 曲线分段要同时处理四件事

| 变量 | 实际要决定的内容 |
|---|---|
| 轴线路径 | 根、中段、末端与前后/左右漂移 |
| 截面 | 各高度内外宽度、前后厚度、非圆截面与收放 |
| 表面方向 | 每一列外表面自身的切线、横向边与法向 |
| 姿态 | 整个部件的摆放或绑定后的刚性旋转 |

轴线变直不要求表面变直；半径或截面变化时，外表面的切线也会变化。只旋转一整圈使其跟随中轴，仍可能得到台阶状表面。

先分别描出可见内缘、外缘及关键切面。长直处保留长段；曲率改变、急转、截面收窄、层次切换和连接处增加必要分段。不要均匀细分整条路径，也不要把同一规则多边形截面不断等比放大。前、后、内、外的面列可以有不同的转折位置和段长。

图像空间可用 `atan2(Δu, Δv)` 表示相对画面向下的方向角，相邻转折取有符号最小角差。它只描述屏幕线段，不能直接写入三维 Euler。短段且读点误差较大时，角度只能作定性参考。

旋转薄 Cube 可作为带厚度的局部面板，围成袖壳、曲面衣片、发盖或带体；其平滑观感来自实际表面方向与接线。参考中的硬折角、开孔和断层应保留，不把所有边都圆滑化。

## 3. 从明确端点构造局部坐标架

先由观察决定端点、宽厚和朝向，再进行下列算术。`A` 对应局部 `+Y` 端，`B` 对应局部 `−Y` 端，不要求 A 的世界高度一定较大。

```text
L = |A - B|
C = (A + B)/2
up = (A - B)/L
right = normalize(h - up · dot(h, up))
normal = right × up
R = [right  up  normal]       # 三列分别为局部 X、Y、Z 在输入空间的方向
S = [width, L + overlap, depth]
```

`h` 是明确选择的横向提示，例如已验证表面的横轴，或按已观察朝向给出的 `[cos θ, 0, −sin θ]`。它决定薄片怎样绕长轴扭转，不是可以从中心线自动恢复的答案。相邻段可把上一段横轴投影到当前切线的垂面中作为连续性起点，再按参考修正扭转；不得忽略参考明确的翻面。

若已知的是表面法向提示 `n_hint`，也可先将它投影到 `up` 的垂面并归一化，再令 `right = up × normal`。两种方法都需检查方向符号，避免一段的表面或纹理突然翻转。

端点重合、宽厚非正、提示方向与长轴近乎平行时应拒绝计算并重新指定输入，不能默默产生 NaN 或随意选择朝向。不要直接平均跨越 `±180°` 的 Euler 数值；使用方向、矩阵或适当的四元数插值处理姿态连续性。

### 表面端点与体积中心端点分开

若描形输入 `QA/QB` 定义的是外表面中心线，厚度向内建立：

```text
C_cube = (QA + QB)/2 - normal · depth/2
```

若输入本来就是 Cube 体积中心线，则不减这项。混用两种定义会把整层向外增厚，破坏轮廓与饰边间距。已存在面板的外表面中心可由真实世界中心加 `normal · depth/2` 得到，前提是厚度轴和世界尺度已正确读取。

### 旋转顺序必须实测

曾使用的 Blockbench 5.1.6 原生 Cube 显示旋转顺序为 `ZYX`。不能假设所有版本、格式、插件或其他软件都相同。用已知非单轴旋转的小样核对目标的矩阵和端点。

本文采用列向量与 `R = Rz(z) · Ry(y) · Rx(x)`。在 SciPy 中，对应：

```python
rotation_xyz = Rotation.from_matrix(R).as_euler('ZYX', degrees=True)[::-1]
```

返回给原生参数的列表仍是 `[x, y, z]`。SciPy 大小写表示不同旋转约定；不要只看到列表顺序就替换调用。Euler 在奇异姿态下不唯一，验证重建矩阵与几何，不以三个角的字面值是否相同作为标准。

## 4. 只做端点算术的工具

[cube_segment.py](../scripts/cube_segment.py) 使用 Python 标准库，读取明确输入，输出中心、尺寸、`from/to/origin`、ZYX 约定的 `[x,y,z]`、坐标轴、端点与八角点。它不编辑模型、不猜参考轮廓，也不保证相邻件接面或无碰撞。

示例输入；数值只是独立算术示例，不是角色模板：

```json
{
  "coordinate_space": "world",
  "rotation_order": "ZYX",
  "segments": [
    {
      "name": "example_segment",
      "a": [0, 2, 0],
      "b": [0.5, 0, 0.25],
      "width": 1,
      "depth": 0.2,
      "width_hint": [1, 0, 0],
      "overlap": 0
    }
  ]
}
```

```text
python "<skill目录>/scripts/cube_segment.py" "<明确输入.json>" --json-out "<计算结果.json>"
```

`overlap` 表示额外总长度，沿局部 Y 两端各延伸一半。不要把它当成每端延伸量。输出的 `from/to/origin` 和八角点处于声明的输入坐标系；存在旋转父组时，必须转换到实际编辑接口所用坐标系后再写入。若只需延长一端，明确重选该端点，不使用对称 `overlap` 冒充。

工具只支持这里声明的 ZYX 约定；退化输入、未知字段、重复输入名称和不支持的旋转顺序会报错。输出文件只能为 JSON，不能覆盖输入文件或 `.bbmodel`。名称唯一仅约束这份输入，不证明编辑器里没有同名对象；仍须核对 UUID。

## 5. 接缝按外表面与真实端面修

两条中心线共用端点时，旋转后的边角仍可能错开。宽度、厚度、扭转不同会造成内侧漏缝、外侧角片或交叉面。将“中心线接上”与“表面接上”分别核查。

| 现象 | 优先处理 |
|---|---|
| 接口能看见背景 | 核实真实端点、旋转原点、父变换和长度，再调整局部接面 |
| 一圈圈台阶 | 检查每列外表面切线及截面变化，不只跟随中轴旋转 |
| 白尖、鳍片、细长矩形端头 | 端面越过邻面或搭接过大；收回越界角并校正旋转 |
| 没漏缝但闪线/小三角跳色 | 近共面重叠或轻微贯穿；检查面距与重复几何 |
| 色带断成几块 | 色带沿用了旧壳面，重新依附实际外表面 |
| 末端某侧不均衡 | 核查终端包络、接头平面及投影压缩，不把上段非对称扩散到袖口 |

实际修接步骤：

1. 隔离一列或一对问题 Cube，同时保留可辨认的邻接面。标出应保留的外轮廓与接头位置。
2. 获取旋转后的外表面、端面和八角点。使用有意义的接头轴，或采用中心轴并显式重算端点，避免小角度引起意外位置漂移。
3. 先小幅调旋转，使表面切线和横向边沿真实方向接续，再微调长度、宽度或中心。对接头两侧共同调整，不只拉长其中一片。
4. 必要时让端部在内部有小量交叠，取能闭缝的最小值；逐面检查是否有角越过外表面。不存在可照抄的统一搭接常数。
5. 在正面、两侧、斜后及接头下方复核。外表面和接线稳定后再恢复其他层，检查遮挡与颜色窗口。

从既有面列中心构造相邻中点，可以作为接线的数值起点；历史使用也曾产生末段散片，因此不能当作无缝保证。急转处可缩短必要段并校正各自横向方向；不要用额外盖片隐藏错误或无限增大重叠。

视觉接面连续不等于几何拓扑焊接。多个相交 Cube 仍是独立体；需要封闭流形或特定导出拓扑时另行核验，不能用“无缝”混称。

## 6. 将末段接入袖口或共同端平面

袖口、环口和多层边缘先使用统一的局部中心、轴向和已观察截面，再让进入它们的各个表面接到合适位置。末端包络应符合参考，不能因为上段各面不同就任意放大某一侧。

对已明确的接头平面 `n·(X-P)=0`，沿既有表面长轴 `u` 从起点 `S` 求交：

```text
t = dot(n, P - S) / dot(n, u)
E = S + t·u
```

分母接近零时线近平行于平面，应重新检查轴向；交点跑到很远或反向也须诊断。然后以真实起终点重算该片方向和尺寸，保住另一端已通过的接线。

**只让中心线交到平面不够。** 检查末端四角 `E ± right·w/2 ± normal·d/2`，以及实际搭接延长后的角点。Cube 端面垂直于自身长轴，不能任意斜切；必要时调整方向、局部宽厚或隐藏接入深度。

可将角点变换到袖口局部坐标，对明确的凸截面使用半空间 `nj·v ≤ dj` 检查越界；这只是包络检查。离散袖口 Cube 之间可能有空隙，位于凸包之内也不代表被实体包住，必须结合真实几何和斜视图。

保留白边、色边、内衬各自真实厚度，使用同一基准面安排层间间距。删除多余末段前确认它已被前段正确接替，不能一刀切缩短所有片。

## 7. 斜边、三角薄片与包边

纯 Cube 不能精确形成任意斜切实体。对参考中可用薄片近似的斜胸片、布尾或镶边：

- 先建立共同局部平面与正厚度，按明确轮廓布置填充条；长斜边使用沿斜向旋转的连续窄条。
- 填充条与斜边在内部轻微相交，保留外斜边位置；检查三角漏隙、叠色、外露矩形端面和背面厚度。
- 各条尺寸来自本片轮廓，不批量套均匀楼梯。尖端需有可编辑的有限宽厚，不用零尺寸或长针状碎条假装精确尖角。
- 包边、内嵌线与薄片共用表面坐标架，边角相交也要检查。避免多个边条在角上交叉、把下摆高度叠成双层，或让装饰与表面共面闪烁。

共同表面的偏移公式和分层附件见 [连续部件与层次](continuous-parts-and-layers.md)。最终记录剩余可见近似误差；允许 Mesh 时可选择更适合的拓扑。

## 8. 保留原曲面来调整胳膊轴线

用户认可现有曲线袖体后，“调直”不能解释为替换成新的圆筒或锥形。先区分要调整左右轴线、前后轴线、整体摆姿，还是局部鼓起；能从用户标注和上下文确定时直接落实。

1. 保存旧件、UUID、父组、截面差异、袖口与肩部挂点。黑带、扣、腕、裸手或手套等关联件一并登记，不能自动镜像不同手部。
2. 由实际袖面读取既有分段中心 `ci`，明确需要固定的肩端、袖口端及分段参数。袖子画面中点不自动等于肘骨位置。
3. 将中心调整到已指定的新轴 `ci'`，保留各面相对该截面的偏移。最简单的局部平移是 `pij' = pij + (ci' - ci)`；需要转向时用明确的截面旋转 `Qi`：`pij' = ci' + Qi·(pij-ci)`。
4. 若只要求侧面顺直，可只调整深度路径，保留已经确认的正面曲线。不要为修一个方向而重置所有坐标和宽厚。
5. 根据原有纵向邻接关系重新校正各面切线和端头；保留原截面收放、非对称面与可见纹理。平移分段后接线不会自动保持，须按前述接面步骤复核。
6. 贴面附件使用同样的承载面变化更新；终端遵守袖口/肩面约束。只有需要整体小幅摆姿时才对装配体施加同一刚性变换。
7. 比较前后多视图、对象范围、接头和附件，明确记录“轴线改变了什么、原形保留了什么”。用户要求回退时恢复指定原件并验证实际数据。

### 局部仿射近似的限制

小幅非均匀调整可用位移场的局部 Jacobian `J` 辅助估算。若原方向为 `R`，对 `A=J·R` 作 SVD 得到最接近的适当旋转，再由 `Rnewᵀ·A` 的对角项估计尺寸变化；需做行列式修正并保证尺寸为正。

其非对角项表示剪切，普通旋转 Cube 无法精确表达。该方法曾用于既有面的小幅修形，但不保证保形、接面或轮廓完全不变；必须比较变换前后角点残差和实际图像。明显剪切时回到显式表面/端点调整，不宣称无损变形。

## 9. 调直与骨骼绑定分开验证

这里沉淀的经验不构成已验证的完整双臂绑定或动画方案。历史续作中的新造直袖被用户否定并恢复原曲面；后续完整骨骼动作验证没有完成，不能把试作骨架当成可复用成品。

需要绑定时，在保留原形的工程副本上，根据参考与目标动作确定关节位置、休息姿态和组层级。重挂父级使用保持世界变换的矩阵换算，见 [编辑与验证](blockbench-editing-and-validation.md)。先比较绑定前后角点与静态投影，再检查必要的屈伸/旋转姿态、袖口和附件，并验证返回休息姿态后几何一致。

分组/骨骼的刚性带动不是蒙皮平滑变形。一个 Cube 跨越多个关节时，不会自动产生连续柔性弯曲；处理方案必须满足目标格式与用户允许的几何表示，新增骨骼也计入对象预算。
