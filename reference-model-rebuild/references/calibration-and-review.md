# 校准与投影叠图规范

用于让同一个三维部件在所有已有参考中一致成立。视图数量、角度、比例和误差阈值由本次参考确定；不套用旧项目标尺。

## 记录可复现的图像映射

保留原始图片及尺寸。裁切、等比缩放或局部放大时记录原图区域，所有标注点应能转换回原图。不要覆盖原参考。

| 项目 | 应记录的内容 |
|---|---|
| 图像坐标 | 原图/裁切图、坐标原点、横纵方向、裁切偏移和缩放 |
| 世界坐标 | 主体轴线、基准面、单位、正面与左右方向 |
| 相机 | 对应参考、是否镜像、投影类型、位置/目标/朝向、角度单位 |
| 比例 | 像素/模型单位或正交视域；透视时记录视场角/焦距及距离 |
| 输出 | 画幅尺寸、渲染区域、背景、模型版本及相机版本 |

统一的是模型的世界尺度。不同来源图片若缩放不同，可有不同的像素比例，需分别记录其相机映射；不能为追求相同像素尺寸扭曲图片或模型。

坐标示例：若 +X 在正面图向右、+Y 向上，正面正交图中线为 `cx`、基准高度像素为 `g`、比例为 `s` 像素/单位，则 `X=(u-cx)/s`、`Y=(g-v)/s`。背面相对于同一世界坐标的水平映射反向。深度不能从单张正面图直接读出。

这只是坐标声明示例，不强制改变现有工程坐标。使用已知方向的点验证工具的朝向和旋转符号，再保存参数。

## 选择并拟合相机

1. 观察透视会聚、近远缩放与可见侧面，选择正交或透视。参考标签不能决定投影类型。
2. 用主体基准、中心轴和稳定尺寸建立整图比例及摆放。附件极值、阴影边界不自动等于主体基准。
3. 根据不同位置、不同深度的对应特征调整偏航、俯仰及必要滚转，交替校正基础体积。一次只改变可归因的一小组变量。
4. 对每张可用参考保存匹配相机，锁定用于后续对比。另设严格正交或斜视诊断相机检查厚度和空间连续性。
5. 相机变更时保留版本记录，重拍所有受影响的比较图。旧相机下的“通过”不能直接作为新一轮证据。

相机拟合需要真正的同一特征对应，不能把不同部件的邻近边缘当作同一边。一个局部点重合不足以确定整体相机。

单视图只能约束其可见投影；新增的侧后诊断图用于检查合理性，不表示缺失的侧后参考已经被匹配。带角度的侧图与严格侧视不能直接作逐像素误差比较。

## 根据偏差选择修正对象

| 可观察现象 | 优先核查 |
|---|---|
| 许多部件同时同向平移 | 裁切、相机目标、基准或中心轴 |
| 差距随离中心距离增加 | 整体比例、正交视域、透视设置 |
| 一幅图成立，另一幅出现系统性的深度错位 | 朝向、俯仰、前后轴、视图对应 |
| 周围边界匹配，单一部件偏离 | 该部件的顶点、位置、朝向或厚度 |
| 外包范围接近，内侧转折和宽度变化不同 | 真实轮廓、局部截面和拓扑 |
| 外轮廓接近，开孔、缝隙或露出层不同 | 内外层边界、搭接与遮挡 |
| 轮廓和遮挡稳定，主要差异是明暗 | 材质、反射和照明，先用中性显示复核 |

该表是诊断起点，结论需要其他视图支持。避免一遇到差异就移动相机，或将所有视角问题都解释为厚度错误。

## 执行一次完整比较

1. 保存工程，按锁定相机与画幅输出模型投影；检查区域不包含工具栏、选中框、网格或变换手柄。
2. 让原参考和投影按固定映射叠合，约50%透明度可作为起点；同时保留原参考及纯模型图。需要时加轮廓线或局部放大。
3. 实际打开所有参考角度的叠图，观察并自行写入审计。先查轮廓和关键点，再查内部边界、厚度、孔洞与遮挡，最后看局部切面。
4. 选择影响最大的当前问题，修改对应几何或经诊断需要改变的相机参数。
5. 重新输出相关视角，实际查看改前与改后，确认没有把问题转移到另一视角或邻接部件。
6. 更新审计状态、证据图路径和下一项动作。只有相应基础阶段成立，才增加依赖它的层次。

叠图只是检查媒介，生成它不会自动产生审计结论。裁切和展示缩放不能改变参考内容；不得对部件区域做独立平移、拉伸、重绘或修补来改善重叠效果。

隔离部件时，只比较参考中属于该部件且真正可见的片段。参考里的外层轮廓不能作为被遮内层的边界；透明叠图中的穿透显示也不等于原参考真实可见。

## 简洁轮廓与额外诊断视图

需要描线比较时，可用蓝色表示实际观察或用户标注的参考边，绿色表示固定相机下真实模型实体掩膜的边界。用户指定了展示方式就沿用。只描外轮廓及有意义的孔边；密集 Cube 线网、隐藏边和每片接线不作为主要还原证据。纯模型、原参考和约 50% 叠图仍须保留。

严格左侧和右侧诊断都要看，必要时增加斜后、顶面或袖口下方。斜侧参考中看似顺直的带体，可能在严格侧视变成很大的三角支架；正面弧形的深盖片，也可能在侧面成为平顶。诊断相机单独命名，不能混作匹配参考的侧相机。

裁切或放大前后沿用同一映射。比较保存前后的图时，可分别比较实体掩膜和 RGBA；轮廓相同而少量明暗像素不同，只能说明轮廓保持，不能报告所有像素完全一致。共面重叠和抗锯齿都可能引起差异，应根据现象继续定位。

## 通过实际遮挡物定位问题

当眼睛、发饰、带扣或发根的可见性异常时，先检查遮挡链，不直接把目标物朝相机推近。

1. 从当前工程取得目标的真实世界几何与相机矩阵。`origin` 可能是偏心旋转轴，不可当作世界中心；父组和场景偏移也必须计入。
2. 对目标的中心及需要露出的边缘取多个观察点。透视相机从相机位置向该点发射射线；正交相机用对应屏幕位置和相机前向构造平行射线。
3. 与实际显示几何相交，按距离记录命中的对象 UUID/名称。检查最前方是否是错误过厚的盖片、恢复后伸出的发根或其他邻层。
4. 排除隐藏对象、辅助对象和材质不可见面；使用透明或 alpha 纹理时，几何命中还需结合像素透明度与实际渲染。单根射线不能证明整个物件可见。
5. 调整真实的遮挡物或层间关系，复拍全部相关相机。恢复一片侧发可能再次挡住饰件的另一翼；每次改层次都复查相邻窗口。

射线查询是定位工具，不是独立验收。原生视图仍须实际打开；不要把“一个取样点无遮挡”写成完整饰件或眼窗已通过。

## 容差和阶段通过

根据原图分辨率、边缘清晰度、抗锯齿、特征大小与读点可靠性确定容差，写明依据。放大图片后需相应换算，不能混用显示像素和原图像素，也不能套固定像素阈值到所有项目。

可记录可靠对应点的像素偏差、局部宽高差、可见轮廓偏离及遮挡是否正确。整体图像相似度会受背景和照明影响，不能单独证明几何成立。

阶段通过需要同时满足：

- 当前可见的高优先级轮廓、关键点和层间关系已在所有相关参考中检查，达到有依据的容差。
- 诊断视图中没有明显异常厚度、悬空、错误贯穿或共面闪线；合理的内部搭接不算缺陷。
- 修改没有破坏已通过部件；隐藏和含糊区域仍保留假设标记。
- 工程已保存，证据图与该版本相符，对象数仍在预算内。

少数关键形状错误不能靠大量正确小细节或平均相似度抵消。未达到条件时继续修当前阶段，或如实交付尚未完成的进度；不将未看过的图和未验证的区域写成通过。
