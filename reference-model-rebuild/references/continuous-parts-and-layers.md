# 连续部件、贴面附件与头发层次

用于衣壳、带体、包边、发束和其他依赖邻接表面的结构。以下角色部件是方法示例；只有本次参考实际支持时才创建，不继承其他角色的颜色、数量、装饰或挂点。

内容索引：承载面绑定；袖口与扣件；衣壳与裙褶；连续布带；头脸与发层；卷发；层次复核。

## 1. 让装饰跟随真正的承载表面

基础几何修形后，旧饰边、绕带和纽扣常会留在原位置，造成断条、悬空或被白色壳面切断。将附件存为相对实际表面的局部关系，而不是另抄一套近似世界坐标。

设表面框架为世界中心 `C`、旋转矩阵 `R`，局部偏移为 `q`：

```text
attachment_center = C + R·q
attachment_rotation = R · R_local
```

若 `C` 是壳体 Cube 的体积中心、局部 `+Z` 朝外，则薄附件中心可用：

```text
q.z = shell_depth/2 + clearance + attachment_depth/2
```

`clearance` 从真实厚度与显示精度确定，不用固定世界数值。需要贴合可用零间隙，不能让两层外表面共面闪烁；几何交叠与实际外表面间距要分清。

跨越多片曲面的包边或绕带，分别依附其承载片，随后检查片间接头。连续长边优先使用能成立的长条，仅在表面转向处拆分。纹理、切线和厚度方向随同一框架更新。参考明确有抬起、折返或离面的部分时，再增加独立路径，不强行全部贴平。

保留源表面 UUID、局部偏移与附件对应关系。基础面被替换时显式迁移绑定；读取旧名称或旧材质找不到源面时应报出，不能默默生成悬空饰件。

## 2. 袖口、绕带、框扣和手部

- 绕带逐面贴合当前袖壳的外表面，各片随截面转向。两条独立带由多少 Cube 围成，与物理带的条数分开记录。
- 框扣用同一局部坐标架摆放边框和底托，检查角点与背面。黑底是实际带体时保留厚度，不把背景色当开孔；参考确有孔洞时由几何边界形成。
- 多层袖口、边缘与内衬统一局部轴、中心和截面基准，各层再设置自身高度、厚度与间距。末端包络按参考保持均衡，不把上袖的局部不对称无依据地延伸到整个环口。
- 进入袖口的末片先修旋转、端面和接入深度；不要靠外加厚罩遮住穿出的端头。数值半空间检查还需真实袖口诊断图，见 [Cube 接面](cube-placement-and-curves.md)。
- 手腕、手套或裸手与袖口一并核对长度、露肤窗口和端点。改变袖口姿态时，按同一明确刚体变换移动应随动的手部，随后复查另一端连接。
- 复制对侧前确认手部、扣件和绑带有无非对称证据。只有一侧戴手套或有扣时，不能镜像成双份；参考不支持逐根手指时不添加无依据细节。

## 3. 身体衣壳、裙褶、腿与鞋

对于参考中具有胸—腰—下摆收放的衣壳，先隔离基础体积，分别检查正面宽度、侧面前后轮廓和背面展开。大盒体上堆装饰无法替代基础收放；也不要只修改胸前一片来掩盖侧面壳体错误。

翻领、胸片、带扣和边缘依赖修好的衣壳。斜胸片的填充、长斜边和内嵌线共用局部平面；黄带等跨层长条必须有连续深度路径，避免被胸片切成互不相连的色块。颜色看似相接时仍需检查实际几何。

裙褶先核对一个可代表拼法的样件，再依据前后各区参考展开。各褶的上窄下展、前后错层、褶谷、白边和色边跟随自己的表面方向；不能给所有褶片套同一世界水平条。褶谷按参考适当内退，并补上确实可见的内层，不能用深色绘制代替结构。

下缘的小块、折角和分段密度来自参考。接着一圈白/深色/亮色边时，逐片继承承载面与局部高度；避免累计偏移造成双倍边高、折角长针或背面露出多余层。前面的褶在背图中受遮挡时，不能与背面的另一褶当作同一件硬对齐。

腿的窄处、鼓起、向靴口回收和轴线漂移分别处理，不能用同宽管替代。鞋面、靴筒、鞋头和鞋底按参考分开校准，保住脚底基准；一张斜侧图的联合投影不足以确定每条腿的完整厚度。扣带等小件在基础体积稳定后按实际壳面安放。

## 4. 连续布带先追踪根，再修完整路径

先确认真实起点与连接对象，再列出根部、背/侧转向、腰髋附近、需避开的衣裙、自由段和末端。用户纠正挂点后整条路径都要复查；不能保留旧路径，只移动第一片或把名称改成新起点。

例如参考或用户明确从肩部起的垂带，要能从肩部连续追踪到末端；这是一项针对当前参考的关系，不意味着所有角色布带都应从肩部开始。

沿路径安排宽度、厚度和扭转，使同一条带在所有参考角度都能对应同一空间结构。较宽的布带还需要稳定横向方向，不能因端点算法的提示向量退化而翻面或突然张开。

### 穿模检查与合理垂落分别判断

1. 检查各相关高度的真实衣裙外表面。旋转 Cube 的 `from/to` 和全物体 AABB 不能直接作为该高度的截面；必要时用实际棱/面与水平面的交线。
2. 让需要在外面的带体绕过真实体积，检查它的宽边、厚边及接头，而非只查中心线。
3. 路径若应沿裙后方，先沿后侧外切趋势绕开，再进入按参考确定的自由垂段，避免为贴一个投影端点而将下段大幅拉到前方。
4. 查看严格左右侧、斜后与全部参考相机。无碰撞的路径仍可能成为巨大的三角撑架，或整条布片不合参考地向外展开。
5. 裙腿穿模与根部浅层嵌入分开登记。肩部连接允许有必要内部搭接，不应为了消灭所有数值相交而制造悬浮挂点。
6. 修接尾部的边条、斜收口和装饰，消除断接、过量搭接及长针状碎片，再复核邻层。

已有试验表明，单纯扩大避让量或强行同时满足不可靠的前后端点对应，会破坏侧面垂落。多视图矛盾时先检查对应、姿态和相机；不能通过不断拉长整张布片来消除一幅图的局部偏差。

碰撞数值可辅助定位，见 [编辑与验证](blockbench-editing-and-validation.md)。通过碰撞检查不能替代轮廓、挂点与垂落方向验收。

## 5. 头脸与发层从内到外组织

根据实际结构选择顺序：头脸基础 → 发盖 → 刘海和鬓发 → 后部宽束 → 长束/外卷 → 依附饰件。个别挂点影响发盖时可交替精修，但每次加层都复查可见窗口。

先区分外轮廓、片间接线、真实孔隙、阴影色块、凸起装饰和被盖住的发根。发色明暗不同不必然需要新 Cube；额外的高光方块不能掩盖平顶、错层和漏缝。

### 头脸基础与眼窗

按参考确认脸的平面程度、下颌浅折、侧脸厚度与露肤窗口。被头发覆盖的后颅只建需要的承托，不按头发外包范围填成可见肤色盒。

保留已制作的手绘虹膜和专用 UV。斜侧远眼露出过多时，先检查相机、脸侧轮廓、眼片的实际位置和刘海/鬓发遮挡。不要直接涂成肤色、把眼睛移出脸面或随意加厚脸来假装问题解决。此类改法如果只有设想，没有实际复核，就不记录为成功技巧。

### 发盖与冠顶

冠顶需要沿横向和前后两个方向检查转折。把正面拱形沿深度拉成长薄板，会在严格侧面形成平盖。逐片调整表面方向、前后长度、厚度和端点，闭合非参考中的三角漏孔，同时保留真实硬折和层次。

### 刘海、鬓发与后宽束

刘海先还原不齐下缘、束间宽度变化和眼眉窗口，再增加参考可见的薄层。鬓发控制脸侧露出，根部要接入发盖；后宽束要有连续根部、各自宽厚变化和前后错层。不要把所有片统一缩放、同高截断或变成等宽丝带。

发根应隐藏在合理的覆盖层中，不能从饰件边缘穿出来。缩窄发盖使大饰翼露出后，恢复一片发根又可能挡住窄饰翼；需要按遮挡链逐层检查，不能把一次改善当成头部整体完成。

## 6. 长发与开放卷发

逐束明确根、中段、端头的宽度、厚度、朝向与分层关系，再构造路径。不同视图看到的最低点或最外点，可能属于不同发束；缺少可靠对应时分别保留候选，不能硬合成一束。

参考中的多边形卷发可由有限的旋转厚条构成：从根部下行、外张、返折、回钩，再向端部收窄。每个转折来自观察，孔洞由开放路径自然形成；不要用闭合圆环、填满的圆盘或孤立圈块替代。

长直段不因“更细”而反复切碎，急转处缩短必要段。使用实际端面和法向修接，避免回钩上长出矩形端头；顶视、侧后和隔离图都要检查孔是否开放、厚度是否突然扭转、根部是否断开。

参考明确是硬折的地方保留折角，表面无意的裂缝与翘片另修。视觉连续与保留多边形造型并不矛盾。

## 7. 发饰与层次复核

发箍沿发盖本身的曲面摆放，凸片或褶边有独立而受控的离面高度。蝴蝶结、十字夹和其他饰件按参考的数量、层次与挂点制作；带孔饰件保留真实空隙，不用实心盒上画暗色代替。

饰件被挡时，查询相机到真实目标几何的遮挡物，方法见 [校准与叠图](calibration-and-review.md)。优先修过厚发盖、错误发根和相互关系，而不是只把饰件朝当前相机拉近。

每次局部完成后复查：原先应露出的脸、眼、饰翼、孔和发缝是否仍露出；应隐藏的根与内层是否仍隐藏；其他角度是否新增穿模。发箍薄片、刘海叠层或一侧饰翼的局部改善，只能支持对应项通过，不能推导整个头部还原完成。
