# 自定义 UV 与跨 Cube 连续花纹

用于手绘眼纹理、鱼网、条纹和其他依附分段曲面的图案。材质花纹用于表达表面信息，不能把整张参考贴到平面上当作三维形体通过的证据。

内容索引：保护已有 UV；世界表面取样；连续相位；atlas 与逻辑 UV；应用和复核。

## 1. 几何编辑前保护已有纹理

先记录受影响对象每个面的材质引用、UV 矩形、UV 旋转、箱式/逐面 UV 模式，以及纹理图片与逻辑分辨率。保存已有手绘虹膜、瞳孔、高光或其他定制图案的源图，不用纯色材质或自动 UV 覆盖掉成果。

曾用 Blockbench 适配器的 `edit_element` 会调用 AutoUV；因此“只改几何”也可能破坏自定义图案。每轮几何调整后读回实际 UV，再根据变形性质恢复原映射或重新烘焙。需要自定义逐面映射时，确认箱式 UV 已关闭，并按当前接口更新面材质和 UV 显示。

手绘纹理先按参考辨认色块、瞳孔形状、高光与边缘，保证原图像素和 UV 比例对应，再检查近景与正常观察距离。不能因为纹理精细就忽略眼片的厚度、脸面贴合和侧面可见范围。

眼睛侧面露出过多优先按相机、几何与遮挡诊断；不要用重新涂色掩盖。修改虹膜以外部件时，仍需验证它没有触发已有眼纹理重排。

## 2. 先从实际世界表面导出烘焙输入

分段袜腿等曲面若每片 Cube 都从 UV 零点重新画图，会在接缝处断线或错相。将图案建立在同一可解释的空间参数上，再分别烘焙到各个可见面。

导出目标面的 UUID、面方向/顺序、实际世界四角、源材质、现有 UV 和所用坐标框架。父组旋转、厚度和几何修改都要计入；存储的 `from/to` 不能直接代替已旋转表面。

对每个 atlas 面片内的像素，用该面的 UV 方向反算面内位置，再由正确排序的四角插值得到世界点。旋转、镜像面和工具的上下方向需要通过已知标记核实，不能给六个面机械使用同一角序。

源几何、腿中心线或烘焙所依赖的相对位置改变后重新导出。单纯刚性摆姿若连同图案坐标框架一起移动，可保留既有 UV；仍须检查接头和显露范围。

## 3. 用共享相位构造连续鱼网等花纹

以已经明确的中心线和横向框架定义纵向参数 `s` 与周向角 `θ`。近乎竖直的部件可采用共享世界高度；弯曲部件需声明沿线参数和截面框架。中心线来自当前造型，不由花纹脚本猜测。

一种交叉网线的相位表达为：

```text
u = repeats_around · θ/(2π) + phase_u
v = (s - s0)/pitch + phase_v
thread_1 = periodic_distance(u + v)
thread_2 = periodic_distance(u - v)
```

`periodic_distance(q)` 可取 `abs(q - round(q))`，靠近整数相位处绘制线。宽度、密度、交叉角和颜色根据参考设置；统一相位原点防止每块从头重置。闭合周向需要整数重复数或其他明确的周期闭合方式，检查角度绕回接缝。

世界点逐像素计算相位可避免跨 `±π` 处直接插值角度产生的跳变。这里的周向角映射不保证非圆截面上的物理线距处处相同；需要近似等距时另定义沿真实截面的周长参数，不能把角度法称为精确等距展开。

同一层面的几何必须先接好。共享相位能修复图案重置，不能填补真实裂缝或让穿模表面消失。关节处、细侧面、下缘和前后交界都要实际查看。

## 4. atlas 像素尺寸与逻辑 UV 单位分开

图像像素分辨率不一定等于模型的逻辑 UV 分辨率。若图像为 `Wpx × Hpx`，逻辑 UV 范围为 `Wuv × Huv`，像素中心对应：

```text
u_uv = (x_px + 0.5) / Wpx · Wuv
v_uv = (y_px + 0.5) / Hpx · Huv
```

实际 UV 矩形端点按目标工具的采样约定设置；上述公式描述像素中心，不应无条件加到所有 UV 边界。确认纹理的逻辑尺寸、逐面旋转、翻转和工具的 V 方向后再写入。

为每个面岛留出足够 padding，向外扩展边缘颜色，降低过滤或缩小时串色。线条太细时结合参考观察距离与采样做抗锯齿，不能只在放大图上看着连续。atlas 尺寸按密度需求和工具能力决定，不套历史项目分辨率。

六面映射需要稳定排序与可追溯 ID；保持“atlas 区域—对象 UUID—面”一一对应。共享材质图案不代表所有面使用同一 UV 矩形。

## 5. 应用后核查材质发现和完整性

1. 导出前核对预期对象和面数；按实际对象集合或稳定 ID 选择目标。使用材质筛选时，材质替换后同步更新筛选条件。
2. 发现零面或面数明显变化时停止应用并诊断；不要输出一张空 atlas 后声称已重烘焙成功。旧材质名称不再存在是常见原因。
3. 在可撤回编辑中应用正确纹理和逐面 UV，刷新显示并读回。核对所有目标面、空引用、越界 UV 和遗漏面。
4. 保存工程并验证纹理是否嵌入或外部路径是否可解析，不能只依赖编辑器缓存里的图片。
5. 用固定相机查看正面、两侧、背面及局部接缝；同时保留正常比例图，检查线宽、相位、接头、串色及整体明暗。

记录几何版本、图案参数、atlas 尺寸、逻辑 UV 尺寸、面数与实际复核角度。源几何变化后旧烘焙报告失效；保存成功与连续花纹视觉通过分别记录。
