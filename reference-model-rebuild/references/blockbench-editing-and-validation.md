# Blockbench 原生编辑、变换与验证

用于继续已有工程、计算实际几何、保存回退及核查结果。工具和接口以当前实际可用能力为准，不将某次会话的端口、令牌、工程路径或运行时写成通用配置。

内容索引：会话核对；原生编辑；父子变换；只读几何；碰撞；截图恢复；保存与回退；分项验收。

## 1. 先确定正在编辑什么

读取活动项目名称、UUID、保存路径、格式、对象与纹理统计，以及是否有未保存变化。多个同名标签、自动恢复文件和磁盘同名文件可能不是同一状态；先比对内容，不新建一个空项目来冒充续接。

读取现有原生连接或工具说明，查询方法和参数的真实 schema。已有可用连接时复用，不重复启动服务。需要恢复本地连接时验证现有状态，避免多个实例操作不同工程；不要把连接密钥打印进工作日志或技能。

纯 Cube 项目应检查保存元素的 `type`。显示实现中的 `mesh`、`matrixWorld` 或三角面对象，并不代表工程中新增了 Blockbench Mesh 元素。

中文路径与 JSON 显式使用 UTF-8；Windows Python 可使用 `-X utf8`。运行时路径从当前环境查找，不复制历史机器路径。

## 2. 原生操作保持可审计与可撤回

曾用适配器提供 `edit_element`、`add_group`、`add_cube`、`set_parent`、`delete_element`、`save_project`、`apply_texture`、`set_face_uv` 等操作；这些只是已见接口示例，不保证其他会话存在，也不保证同名方法参数相同。先查询当前接口，再调用。

- 操作前读回目标的真实类型和 UUID，名称可重复、旧父组可为空，不能只凭前缀推断层级。
- 每轮只修改明确部件及其必要依赖，记录原值、目标值和预期影响。支持原生 Undo 时将一次局部修改组织成可撤回编辑。
- 批量创建之前检查同名/同义对象和历史执行状态；能编辑原件就定位原件。脚本重跑不一定幂等，重复 trim 会继续缩短，重复 create 会增加副本。
- 命令行工具被其他脚本导入时不应自动读取参数并执行操作，使用明确入口保护。依次检查每条原生操作结果，失败后重新读取实际场景再续接，不整批盲目重放。
- `edit_element` 在曾用适配器里会触发 AutoUV；几何改完还需恢复或重烘焙受影响的自定义 UV。详见 [UV 专题](uv-and-surface-patterns.md)。

只读导出、算术和检查可用脚本完成，形状选择仍依据本次观察。历史生成文件仅作溯源，不当作默认正确模板。

## 3. 组原点、父矩阵与保持世界位置

在已用 Blockbench 接口中，单改 `Group.origin` 改的是旋转轴，不等于平移所有子件。已有的“移动组”脚本也可能只移动直接 Cube 子件，不能推断它会递归正确处理子组。

执行部件平移前先确定字段的坐标语义、完整后代列表和父组旋转。普通局部坐标图与 Blockbench 某些格式的几何字段编码并不完全相同；不能机械地对所有层级加同一向量，也不能把改组原点当作整个装配体已移动。

可靠的原则是先定义目标世界变换，再依据工具语义回算。对现有世界变换 `W` 和新父变换 `Pnew`：

```text
Lnew = inverse(Pnew) · W
```

重挂父级后按格式正确编码 `Lnew` 对应的中心、旋转、尺寸和原点，再比较实际世界角点。`set_parent` 不保证自动保持世界姿态；旋转父组下直接复制旧局部数字，可能二次旋转或位置跳动。

围绕明确世界枢轴 `p` 对一个装配体施加刚性旋转 `Q` 时：

```text
Cnew = p + Q·(Cworld - p)
Rnew = Q·Rworld
```

再换回各对象实际父坐标系。不要在已有旋转的父组上直接逐项相加 Euler 角。装配体有嵌套组时，选择一致的实现层级，避免父组和子件把同一变换应用两次。

父级存在非均匀缩放、镜像或剪切时，普通 Cube 旋转加尺寸未必能无损表达目标矩阵。检查行列式、轴正交性和分解残差；不能宣称保持世界变换，除非读回后的角点及必要法向确实相符。

## 4. 获取真正的世界几何

优先使用当前编辑器评估后的实际角点、轴向和相机投影，或严格按已验证格式重建完整父变换。取 `from/to` 的八种组合后，还需要自己的 pivot 旋转、父变换以及适用的缩放/膨胀/场景偏移。

不要将以下数据混用：

- 存储的 `origin` 与实际几何中心；
- 未旋转边界与世界 AABB；
- 局部表面法向与世界法向；
- 世界角点、相机空间点与已经裁切的像素坐标。

使用已知点核对独立数学投影与原生投影，一致后再用它量尺寸或回算位置。相机映射可复现不代表原参考相机被唯一恢复。

对既有表面做饰边、UV 或接面导出时，输出源工程标识、对象 UUID、坐标约定与几何版本。源面更改后旧导出失效，不能把它当作当前几何继续计算。

## 5. 用 OBB/SAT 辅助查穿模

这里的 SAT 用于正交长方体的只读相交诊断。先用世界 AABB 排除明显分离的对象，再对候选做窄阶段。若实际变换包含剪切，或形体不是盒体，不能强行当 OBB；改用相应真实几何检查。

设两盒中心差为 `D=CB-CA`，单位轴为 `Ai/Bj`，半尺寸为 `ai/bj`。候选轴为 A 的 3 轴、B 的 3 轴和 9 个两两叉积，近零叉积跳过。每个候选轴归一化为 `L` 后：

```text
rA = Σ ai · |dot(Ai, L)|
rB = Σ bj · |dot(Bj, L)|
signed_overlap = rA + rB - |dot(D, L)|
```

存在显著负值即分离；接近零是接触或数值不确定区；所有有效轴均显著为正才构成盒体穿入。可记录最小正值及轴作为诊断，但不要把未经归一化的叉积结果当世界距离。

容差按模型尺度、数值精度与实际必要间隙设置，不能照抄固定阈值。记录参与检查的对象集合、碰撞对 UUID、深度/接触读数和工程版本；空的候选集合不等于通过。

肩部或接头的必要浅层嵌入与布带穿进裙腿分开处理。不要为了达到“零相交对”而拉开原本需要连接的部件。视觉孔洞或透明纹理也可能使实体碰撞与看到的形状不同，结论须注明检查表示。

检查结果只说明这些几何在该姿态下是否相交，不验证垂落、轮廓、可见性、其他动画姿态或参考还原程度。

## 6. 截图和临时显示状态可恢复

固定相机、输出大小、裁切和背景，获取原生模型投影。需要隔离部件或纯色掩膜时，先记录每个受影响对象原有的可见性、材质和显示状态；在 `finally` 等可靠恢复路径中逐项恢复，不统一设为“全可见”。不要把隔离态误存为交付态。

去除选中框、变换手柄和网格后检查实际输出。曾用版本里仅调用 `unselectAllElements()` 仍有残留描边，配合 `updateSelection()` 才刷新；在其他版本应查询等效方法并查看结果，不假设函数返回就代表画面干净。

遮挡定位可读取实际显示几何作射线查询；完整方法见 [校准与叠图](calibration-and-review.md)。正式比较保留原图、纯模型和叠图，蓝/绿线取观察轮廓和实体边缘，不把所有 Cube 线网当作主要图像。

## 7. 检查点、保存、读回与回退

开始续作、改基础体积或回退前保存当前未保存状态。明确“磁盘文件”“当前打开项目”“将交付版本”三者，工程标签或较大的版本号不能证明内容更新或质量更高。

保存后重新读文件，检查可解析性、工程格式、对象、纹理及层级；需要交付时在原生编辑器读回并查看。截图证据必须对应保存后的状态，记录相机版本及必要的文件摘要。

用户要求撤销某项改变时，先列出被撤回对象与无关修改。若整份旧检查点会丢失其他成果，恢复对应部件及关联数据；只有范围确实一致时才整份回退。回退结果比较实际元素、尺寸、旋转、分组、父子关系及受影响纹理/UV，不以对象数相同替代。

保存前后轮廓掩膜一致可支持轮廓保持，但 RGBA 少量像素不同仍需如实记录。不要将“文件能打开”写成“所有数据与显示完全相同”。

用户叫停后保留当前检查点，记录未完成或未验证部分；不为了让最终报告更好看继续修改造型。

## 8. 将验证拆成独立结论

| 检查 | 能支持的结论 | 不能替代的内容 |
|---|---|---|
| 对象统计、部分 UUID/层级引用 | 保存文件在统计范围内的数量及身份检查 | 全部层级语义、几何质量、视觉还原 |
| 正尺寸与角点 | 需要正厚度的 Cube 没有退化/反尺寸，变换在可检查范围内 | 接面、正确截面或材质 |
| 纹理引用、嵌入图、UV 读回 | 受检表面材料数据完整 | 图案连续性、造型与光照 |
| 接头连通与 SAT | 所查接头/实体的连接或相交关系 | 合理垂落、遮挡与多姿态表现 |
| 原生保存与读回 | 交付工程可读取、内容可核对 | 参考中的每个细节通过 |
| 多视图叠图及诊断图 | 对应版本中实际看过的可见约束 | 被遮住或无参考的结构真值 |

[audit_bbmodel.py](../scripts/audit_bbmodel.py) 只统计保存元素、去重分组与工程参考，并做部分 UUID/引用检查。它不校验正厚度、材质、UV、穿模或视觉；对这些项目须另取数据或实际检查，报告不扩大脚本能力。

对象预算包含隐藏元素、空组/骨骼和保留的参考对象。纹理和关键帧不计作几何对象，但材质质量、面数和编辑流畅度仍需检查。显示渲染网格与保存模型元素类型也要分开。
